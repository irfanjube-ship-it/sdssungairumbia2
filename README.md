# Website SDS Sungai Rumbia 2
Website resmi SDS Sungai Rumbia 2 yang berisi informasi tentang profil sekolah, fasilitas, tenaga pendidik, berita, dan kontak.

## 🛠 Teknologi yang Digunakan
- HTML5
- CSS3
- JavaScript
- Desain responsif (dapat dibuka di ponsel, tablet, dan komputer)

## 📂 Cara Menggunakan
1. Unduh semua berkas dalam repositori ini
2. Simpan dalam satu folder yang sama
3. Buka berkas `index.html` di peramban web
4. Anda dapat mengedit konten sesuai kebutuhan sekolah

## 📝 Keterangan
- Gambar dapat diganti dengan foto asli sekolah
- Teks dan informasi dapat disesuaikan dengan data yang benar
- Dikembangkan untuk keperluan informasi dan promosi sekolah

## 📞 Kontak
Jika ada pertanyaan atau perbaikan, silakan hubungi pengelola sekolah.
